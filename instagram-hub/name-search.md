# Module: Name and Username Search (SEO)

**One job:** make the page's display name, username and overall profile easy to find in Instagram search.

## How Instagram search works (be honest)

- Instagram search matches mainly on the **Name field** (separate from the username), the **username**, the **bio** and the **topic keywords** the page is associated with.
- The Name field is the strongest lever: it is searchable and can contain a keyword (e.g. "Sara | Home Baking"), while the username should stay short and clean.
- No one outside Instagram knows the exact ranking formula. Never promise "first result in search". Say this raises the chances.

## Steps

1. Ask for the niche, audience, language/market and city (if local) if not already known.
2. Research real search demand when web search is available: look for the words people actually use for this niche in the user's language (related searches, popular pages in the niche, common phrases). Do not invent popularity numbers. If you cannot verify demand, say "this is a reasoned suggestion, not measured data".
3. Check that the keyword is natural, not spammy. A name stuffed with keywords looks fake and hurts trust.

## Rules

- **Name field (up to 64 characters):** brand/person name + 1–2 main keywords. Example pattern: `Name | Keyword` or `Keyword – Name`.
- **Username:** short, easy to say and spell, no random numbers or underscores chains, close to the brand name. Avoid changing it if the page already has a recognized handle; changing it breaks old links and mentions. Warn the user about this.
- **Bio keywords:** the main keyword should also appear naturally in the first line of the bio.
- **Consistency:** same name and handle idea across Instagram, Highlights, link page, and other platforms.
- Do not suggest names that copy another brand, use trademarks, or impersonate someone.
- Check that the suggested username is not obviously taken: tell the user to test it in the app, since availability cannot be confirmed from here.

## Output

1. Current name/username problems (what hurts search).
2. 3–5 name field options, each with the keyword it targets and why.
3. 3–5 username options (only if the current one is weak), with the warning about changing handles.
4. One recommended pick and the exact text to paste into the Name field.
5. A short list of the other places to repeat the keyword (bio first line, Highlights titles, post alt text, captions).
