# Module: Bio, Link and Highlights

**One job:** rewrite the bio, link and Highlights so a visitor understands the page and acts within a few seconds.

## Bio rules

- Instagram bio limit is 150 characters; keep inside it.
- Line 1: who it's for or what they get, with the main keyword (naturally).
- Line 2: proof or specific detail that is real (years of experience, city, what you actually offer). Never invent numbers or credentials; ask the user, or leave [your detail here].
- Line 3: one clear call to action (message me, order, link below).
- Use line breaks; 0–2 emojis at most, used as separators, not decoration.
- Write in the user's language and real tone. No clichés, no AI-sounding slogans.

## Link rules

- One clear destination. If several are needed, use one link page and keep it tidy.
- The link should match the call to action in the bio.

## Highlights rules

- 4–6 highlights, titled with short searchable words (not vague emojis only).
- Consistent cover style, matching the page's colors.
- Order by importance to a new visitor (start here, services/products, results/reviews, FAQ, about).
- Use only real reviews and results, never fabricated ones.

## Output

1. What is wrong with the current bio/link/highlights (specific).
2. 2–3 bio options, each within 150 characters.
3. Link and highlight recommendations.
4. Ask which bio feels most like the user and refine.
